# Clima Araraquara

Projeto final do 4º bimestre de ARQIWEB2 (IFSP Araraquara). Tema: mudanças climáticas.

App em React + Vite com um formulário de opinião sobre o calor em Araraquara. As respostas são gravadas no Supabase e a tela de resultados mostra a contagem por opção, a média da escala e os comentários.

Dupla: Custódio e Figueredo

Link do app: (colocar o link do Netlify)

## Como rodar

1. `npm install`
2. Copiar `.env.example` para `.env` e preencher com a URL e a publishable key do Supabase
3. `npm run dev`
